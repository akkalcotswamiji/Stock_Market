Frequently Asked Questions

1. What is MarketX?

MarketX is an educational stock-market dashboard for exploring company information and financial concepts.

2. Does MarketX execute stock trades?

No. This project is an educational dashboard and does not execute real stock-market transactions.

3. Are all displayed prices live?

Not necessarily. Some displayed figures are sample values. Actual API availability and data delays depend on the data provider.

4. What is a watchlist?

A watchlist is a collection of stocks that a user wants to monitor.

5. What is portfolio analysis?

Portfolio analysis helps users understand holdings, allocation and performance.

PROJECT INFORMATION

About This Project

MarketX is an educational stock-market dashboard project built using HTML, CSS, JavaScript and a Node.js backend.

Market data availability depends on the configured external API provider.
